# 🏆 Campeões da Copa

Um aplicativo iOS moderno e elegante que celebra a história das Copas do Mundo de Futebol, com destaque para a **Copa de 2026** realizada nos EUA, México e Canadá, onde a **Espanha** conquistou seu bicampeonato!

## ✨ Funcionalidades

### 🌟 Destaques
- **Design Liquid Glass**: Interface moderna com efeitos de vidro fosco e gradientes animados
- **Copa 2026 em Destaque**: Informações completas sobre a última edição do torneio
- **Histórico Completo**: Todos os campeões desde 1930 até 2026
- **Resultados Detalhados**: Finais, semifinais, quartas e oitavas de final
- **Interface Interativa**: Cards em grid com animações fluidas e toque responsivo

### 📊 Copa do Mundo 2026
- **🥇 Campeão**: Espanha 🇪🇸 (2º título)
- **🥈 Vice-campeão**: Argentina 🇦🇷
- **🥉 Terceiro Lugar**: Inglaterra 🏴󠁧󠁢󠁥󠁮󠁧󠁿
- **4º Lugar**: França 🇫🇷
- **Final**: Espanha 1-0 Argentina (prorrogação)
- **Disputa do 3º lugar**: Inglaterra 6-4 França

## 🎨 Design

O app apresenta um visual contemporâneo com:
- **Efeitos de vidro fosco** (blur) em cards e painéis
- **Gradientes animados** que dão vida à interface
- **Cores vibrantes** inspiradas nas bandeiras dos países
- **Tipografia moderna** com hierarquia visual clara
- **Animações suaves** em transições e interações

## 📱 Requisitos

- **iOS**: 16.0 ou superior
- **Xcode**: 14.0 ou superior
- **Swift**: 5.7 ou superior
- **Dispositivos**: iPhone, iPad e iPod Touch

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/campeoes-da-copa.git
cd campeoes-da-copa
```

2. Abra o projeto no Xcode:
```bash
open CampeoesDaCopa.xcodeproj
```

3. Selecione o dispositivo/simulador desejado

4. Compile e execute (⌘R)

## 📁 Estrutura do Projeto

```
CampeõesDaCopa/
├── ContentView.swift          # Tela principal com grid de campeões
├── DetailView.swift           # Tela de detalhes de cada copa
├── WorldCup2026.swift         # Modelo de dados da Copa 2026
├── Models/
│   └── WorldCup.swift         # Modelo genérico de copas
├── Views/
│   ├── ChampionCard.swift     # Card individual de campeão
│   └── GradientBackground.swift # Fundo gradiente animado
└── Assets.xcassets            # Recursos visuais e cores
```

## 🛠️ Tecnologias Utilizadas

- **SwiftUI**: Framework declarativo para interfaces
- **Swift Concurrency**: Para operações assíncronas
- **SF Symbols**: Ícones nativos do sistema
- **Core Graphics**: Para efeitos visuais personalizados
- **Animation APIs**: Animações nativas do SwiftUI
